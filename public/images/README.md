# Изображения учебного журнала «Контур»

Все изображения хранятся локально. Внешние адреса ниже — источники и лицензии, не URL загрузки изображений в браузере.

## Оригинальные обложки

`covers/2026-01.svg`, `covers/2025-02.svg`, `covers/2025-01.svg` созданы специально для этого вымышленного учебного проекта. Это оригинальная векторная графика, не обложки реальных изданий. Размер каждой — 600 × 800.

Обложки предоставляются по [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Цвета соответствуют `src/styles/tokens.css`; шрифт внутри SVG использует системный serif fallback. Внешних шрифтов, скриптов и ресурсов в SVG нет.

Обложка повторяет сведения, уже доступные текстом в `IssueCard`, и не является отдельной ссылкой: используется `alt=""`, чтобы не дублировать название и номер для скринридера.
