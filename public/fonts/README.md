# Локальные шрифты «Контура»

Literata и Golos Text используются в соответствии с утверждённым `docs/design.md`.
Файлы WOFF2 загружены без изменения, для обычного начертания с весами 400–600.
Literata также содержит переменную ось оптического размера 7–72.
Сохранены кириллическое и латинское подмножества; дополнительные алфавиты и курсив не подключены.
Во время работы сайта внешние запросы к поставщикам шрифтов не выполняются.

Оба семейства распространяются по SIL Open Font License 1.1.
Полные тексты с указанием авторских прав находятся рядом:

- `Golos-Text-OFL.txt`: https://github.com/google/fonts/blob/main/ofl/golostext/OFL.txt
- `Literata-OFL.txt`: https://github.com/google/fonts/blob/main/ofl/literata/OFL.txt

Источник сборок — Google Fonts CSS API:
https://fonts.googleapis.com/css2?family=Golos+Text:wght@400..600&family=Literata:opsz,wght@7..72,400..600&display=swap
