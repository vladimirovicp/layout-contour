# Главная: результат этапа

## Согласованный результат

Главная — витрина: один текущий выпуск и четыре статьи из общего набора, а не оглавление этого выпуска. Это согласованное уточнение первоначальной схемы в `design.md` и `page-map.md`.

## Файлы

- `src/pages/index.astro`: `BaseLayout`, существующие `IssueCard` и `ArticleCard`, вводный текст с маркировкой вымышленного журнала и ссылка в архив. Текущий выпуск выбирается по максимальной дате `publishedAt`, независимо от порядка данных; сейчас это `2026-01`. Пустые состояния предусмотрены для выпусков и подборки. Дубли подборки, неизвестные статьи и авторы, несогласованные связи с выпусками вызывают ошибку сборки.
- `src/data/home.ts`: типизированные тексты главной и ручная подборка `open-science-review`, `long-material-description`, `abstract-as-reading-map`, `minimal-metadata-example` — две статьи из текущего выпуска и по одной из двух выпусков 2025 года.

Карточки, layouts, другие страницы, общие стили, токены и зависимости не изменялись. Существующие пользовательские изменения не затронуты.

## Проверки

- `npm run check`: 19 файлов, 0 ошибок, предупреждений и подсказок.
- `npm run build`: успешная статическая сборка, 17 страниц.
- Chromium / Playwright, production preview, 390 и 1440 CSS-пикселей: главная отвечает HTTP 200, один `h1`, одна карточка выпуска и четыре карточки статей, клиентских скриптов нет.
- На обеих ширинах выполнены клики в текущий выпуск и каждую статью; все ответы HTTP 200, заголовки статей совпадают с карточками. Проверены возвраты на главную по названию журнала, ссылка «Все выпуски» и «Архив» в шапке.
- Переполнения главной нет, включая заголовок статьи из 233 символов и размер текста 200%. Ширина подборки — 350 / 792 px; сведения о выпуске на узком экране идут перед статьями.
- Клавиатура: ссылка пропуска переносит фокус в `main`; следующая ссылка ведёт в текущий выпуск, видимый контур фокуса 3 px.
- Astro Container, изменения только в памяти: выбор текущего выпуска не зависит от порядка массива, более новая дата меняет выбранный выпуск; пустое описание скрывается; пустая подборка и пустые коллекции показывают пояснения без пустых карточек; неизвестный slug подборки отклоняется. После успешных проверок при закрытии временного Vite-сервера появилось диагностическое сообщение об отключённом транспорте.
- `git diff --check`: без ошибок пробелов.
