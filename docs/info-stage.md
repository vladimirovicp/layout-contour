# Информационные страницы: результат этапа

## Результат и файлы

Одна композиция для `/about/`, `/authors/`, `/editorial/`, `/contacts/`: заголовок, введение и маркировка учебного проекта; навигация по четырём страницам слева, разделы текста и списки справа. На узком экране навигация идёт перед текстом. Отличается только контент.

- `src/layouts/InfoLayout.astro`: общий шаблон на существующих `BaseLayout` и `Breadcrumbs`, единая типографика на утверждённых токенах, активный пункт с `aria-current`, обработка пустого содержимого и необязательных полей.
- `src/data/info-pages.ts`: типизированные данные всех четырёх страниц. Тексты, участники редакции, правила и email явно демонстрационные. Email `editor@contour.example` выведен текстом и не принимает реальные обращения.
- `src/pages/[slug].astro`: один маршрут с `getStaticPaths` только для четырёх известных страниц; дубли slug отклоняются.
- `src/components/SiteHeader.astro`, `SiteFooter.astro`: включены ссылки «О журнале», «Авторам», «Редакция», «Контакты». Поиск остаётся недоступным текстом.

Другие страницы, layouts, карточки, дизайн-токены и зависимости не изменялись. Предыдущие изменения и пользовательская правка `package-lock.json` сохранены. Формы, backend, внешние сервисы и новые библиотеки не добавлены.

## Проверки

- `npm run check`: 22 файла, 0 ошибок, предупреждений и подсказок.
- `npm run build`: успешная статическая сборка, 21 страница, включая четыре информационные.
- Chromium / Playwright, production preview: все четыре страницы открываются с HTTP 200 на 390 и 1440 CSS-пикселях, имеют один `h1` и одинаковую композицию. Навигация содержит все четыре ссылки и ровно один текущий пункт.
- На каждой ширине проверены все 12 направленных переходов между разными инфостраницами, HTTP 200 и соответствующие заголовки. Дополнительно проверены входы с главной через шапку/подвал и возвраты на главную.
- Горизонтального переполнения нет; колонка текста — 350 / 792 px. На всех четырёх страницах проверены текст 200%, временный длинный заголовок и непрерывный адрес. Тестовый текст не сохранялся.
- Клавиатура: ссылка пропуска переносит фокус в `main`, навигация доступна по Tab, видимый контур 3 px. Форм, полей отправки, клиентских скриптов и фиктивных загрузок нет.
- Astro Container: отсутствующее введение скрывается; пустые разделы не выводятся; пустое содержимое получает пояснение и ссылку на главную; отсутствие абзацев и подписей списка допустимо; HTML в тестовом тексте экранируется. Данные на диске не менялись. После успешных проверок при закрытии временного Vite-сервера появилось диагностическое сообщение об отключённом транспорте.
- Существующие `/`, `/archive/`, `/issues/2026-01/`, `/articles/open-science-review/` по-прежнему отвечают HTTP 200; неизвестная инфостраница в preview — 404, без подмены другой страницей.
- `git diff --check`: без ошибок пробелов; есть предупреждения Git о будущей нормализации LF → CRLF.

## Ограничения

Проверки выполнены в Chromium, не на физических устройствах и не во всех браузерах. Реальных фотографий, организаций, шаблона рукописи и способов отправки обращений нет; они не подменяются заглушками. Поведение 404 на будущем хостинге не проверялось. Публикация не выполнялась.
