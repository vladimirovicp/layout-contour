# Выпуск 2026, № 1: результат этапа

## Результат

- `src/components/IssueCard.astro`: сведения о выпуске из типизированных данных, ссылка на заголовке; на собственной странице выпуска ссылка отключена. Пустое описание не выводится.
- `src/components/ArticleCard.astro`: переиспользуемая запись с заголовком-ссылкой, авторами и полной аннотацией. Поддерживает `h2` и `h3`, отсутствие авторов.
- `src/pages/issues/2026-01.astro`: статическая страница на `BaseLayout`, с существующими `Breadcrumbs`, `IssueCard` и четырьмя `ArticleCard`. Оглавление следует `articleSlugs`; отсутствующая статья, чужой выпуск, повторный slug и неизвестный автор останавливают сборку. Для пустого оглавления предусмотрено пояснение и переход на главную.

Главная, `ArticleLayout`, данные, дизайн-токены и зависимости не изменялись. Существующее пользовательское изменение `package-lock.json` не затронуто. Другие страницы выпусков и архив не добавлены.

## Проверки

- `npm run check`: 17 файлов, 0 ошибок, предупреждений и подсказок.
- `npm run build`: успешная статическая сборка, 14 страниц, включая `/issues/2026-01/`.
- Chromium / Playwright, production preview, ширины 390 и 1440 px: выпуск отвечает HTTP 200, один `h1`, ровно четыре статьи в порядке локальных данных; чужих статей нет.
- На обеих ширинах проверены клики по всем четырём статьям, совпадение их заголовков и возврат через ссылку «К выпуску». Переход из хлебных крошек на существующую главную работает.
- Горизонтального переполнения выпуска и четырёх статей нет. Колонка оглавления — 350 px на узком экране и 792 px на широком; длинный заголовок не обрезается.
- Клавиатура: ссылка пропуска переносит фокус в `main`; заголовок первой статьи доступен по Tab, фокус — сплошной контур 3 px. При размере текста 200% выпуск не получает горизонтальную прокрутку на обеих ширинах.
- Изолированный Astro Container: ссылка `IssueCard`, отключение ссылки на текущий выпуск, пустое описание, отсутствие авторов, пустое оглавление и отклонение статьи чужого выпуска. Тестовые изменения существовали только в памяти, данные на диске не менялись. После успешных утверждений Container сообщил об отключении транспорта при закрытии временного Vite-сервера.
- `git diff --check`: без ошибок.

## Ограничения

- Архив пока отсутствует: в хлебных крошках он показан недоступным текстом, без битой ссылки.
- По прямому ограничению задачи `ArticleLayout` не изменён: его старое пояснение «Страница выпуска готовится» осталось, хотя переход к этому выпуску уже работает.
- В локальных данных выпуска нет обложки, PDF и страниц статей; фиктивные файлы, подписи и действия не добавлены.
- Браузерные проверки выполнены в Chromium, не на физических мобильных устройствах и не во всех браузерах.
