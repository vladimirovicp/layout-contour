# Обложки и фото-иллюстрации: результат этапа

## Согласованный объём

Обложки всех трёх выпусков и фотографии книг и рабочего пространства без портретов людей на страницах «О журнале» и «Редакция». Фотографии не выдаются за реальные помещения, материалы или участников вымышленного журнала.

## Изменённые и добавленные файлы

- `src/data/types.ts`: тип `LocalImage` с локальным путём `/images/...`, обязательными `width`, `height`, `alt`; необязательная обложка выпуска.
- `src/data/issues.ts`: обложки трёх выпусков, 600 × 800. Пустой `alt` осознанный: содержание обложки повторяется рядом текстом и изображение не является отдельной ссылкой.
- `src/components/IssueCard.astro`: необязательная обложка с размерами, ленивой загрузкой и сохранением пропорций. В широкой карточке обложка рядом с текстом, в узкой — над ним. Без обложки пустого изображения нет. Этот же компонент применяется на главной, в архиве и выпусках.
- `src/data/info-pages.ts`: типизированные необязательные фотографии, описательные alt, подписи, авторы, источники и лицензии для двух инфостраниц; уточнено отсутствие портретов вымышленных участников.
- `src/layouts/InfoLayout.astro`: необязательная фотография раздела с размерами и подписью; единый шаблон четырёх инфостраниц сохранён, отдельная композиция для фотографии не создавалась.
- `public/images/covers/{2026-01,2025-02,2025-01}.svg`: оригинальные обложки вымышленных выпусков в палитре сайта, CC0 1.0.
- `public/images/photos/old-books.jpg`, `editorial-desk.jpg`: локальные JPEG, 1280 × 853, приблизительно 135 и 199 КиБ. Авторы — Eli Francis и www.Pixel.la Free Stock Photos; обе фотографии доступны по CC0 1.0 согласно карточкам Wikimedia Commons.
- `public/images/README.md`: происхождение, лицензии, изменения и назначение каждого изображения. Подписи к фотографиям на сайте также содержат авторов, источники и лицензию.

Страницы не копируют разметку изображений или карточек. `ArticleLayout`, тексты статей, дизайн-токены, зависимости и конфигурация не менялись. Предыдущие пользовательские изменения сохранены.

## Проверки

- `npm run check`: 25 файлов, 0 ошибок, предупреждений и подсказок.
- `npm run build`: успешная статическая сборка, 23 страницы.
- Проверка всех 23 HTML-файлов: девять элементов `img`, пять уникальных локальных ресурсов; каждый файл существует, каждому изображению заданы размеры и alt.
- Chromium / Playwright, production preview, 390 и 1440 CSS-пикселей: проверены главная, архив, три выпуска и четыре инфостраницы — HTTP 200, один `h1`, без горизонтального переполнения, включая текст 200%.
- Все изображения декодируются; `naturalWidth`/`naturalHeight` совпадают с атрибутами. Обложки — 192 × 256 при обычном размере текста, фотографии — 350 × 233 / 792 × 528 без искажения пропорций.
- Декоративные обложки имеют пустой DOM `alt`; фото — содержательные описания и подписи с источниками. Внешних запросов при просмотре и неудачных загрузок не обнаружено: внешние адреса используются только как обычные ссылки на источники и лицензии.
- В «Авторам» и «Контактах» нет пустых рамок и подписей к отсутствующим изображениям. Повторно проверены переходы из архива во все три выпуска и обратно.
- Astro Container: выпуск без обложки сохраняет ссылку без `img`; раздел с одной фотографией отображается; отсутствие фотографии не оставляет `figure`/`figcaption`. Тестовые данные не сохранялись. После успешных проверок при закрытии временного Vite-сервера возникло диагностическое сообщение об отключении транспорта.
- `git diff --check`: без ошибок пробелов; Git предупреждает о будущей нормализации LF → CRLF.

## Ограничения

Проверки выполнены в Chromium, не на физических устройствах и не во всех браузерах. Используются готовые локальные JPEG и SVG, без генерации адаптивных наборов `srcset` и новых библиотек. В SVG обложек системные шрифты из запасных стеков; внешние шрифты не загружаются. Иллюстрации статей и портреты не добавлялись; прежний необязательный вывод изображения в `ArticleLayout` не дорабатывался. Публикация не выполнялась.
