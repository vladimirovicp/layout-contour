# Архив: результат этапа

## Согласованный объём

Статичный список всех выпусков в порядке `src/data/issues.ts`, без фильтра, сортировки, группировки и клиентских скриптов. Каждый выпуск использует существующий `IssueCard` и ведёт на свою статическую страницу.

## Файлы

- `src/pages/archive.astro`: архив на `BaseLayout` с `Breadcrumbs`, списком `IssueCard` и пустым состоянием со ссылкой на главную.
- `src/pages/issues/[slug].astro`: прежняя `2026-01.astro` обобщена через `getStaticPaths` для всех трёх локальных выпусков. Разметка не скопирована; `ArticleCard` переиспользуется. Добавлена ссылка в архив в хлебных крошках.
- `src/components/SiteHeader.astro`: «Архив» стал работающей ссылкой; на странице архива имеет `aria-current="page"` и полужирное начертание. Остальные неготовые разделы остаются текстом.

Главная, `ArticleLayout`, карточки, данные, токены и зависимости не изменялись. Пользовательское изменение `package-lock.json` не затронуто.

## Проверки

- `npm run check`: 18 файлов, 0 ошибок, предупреждений и подсказок.
- `npm run build`: успешная статическая сборка, 17 страниц, включая архив и три выпуска.
- Chromium / Playwright, production preview, 390 и 1440 CSS-пикселей: архив и все три выпуска открываются с HTTP 200; в архиве один `h1`, все выпуски показаны ровно один раз, в порядке данных. Клиентских скриптов и элементов фильтрации нет.
- На обеих ширинах выполнены клики из архива во все выпуски, далее во все 12 статей, возврат к соответствующему выпуску и в архив. Оглавления совпадают с `articleSlugs` своих выпусков. Проверены ссылка архива в общей шапке и переход по названию журнала на главную.
- Переполнения документа архива и выпусков нет; ширина списка архива — 350 / 792 px. Архив также проверен с текстом 200%, временным заголовком из 434 символов и длинным непрерывным обозначением. Тестовый текст не сохранялся.
- Клавиатура: ссылка пропуска переводит фокус в `main`, первая карточка доступна по Tab, видимый контур фокуса 3 px.
- Astro Container: пустой архив выводит пояснение и ссылку на главную без пустого списка; пустое описание выпуска скрывается; HTML в тестовом заголовке экранируется, ссылка сохраняется. Данные менялись только в памяти. При закрытии временного Vite-сервера после успешных проверок возникло диагностическое сообщение об отключённом транспорте.
- Неизвестный slug выпуска в локальном preview возвращает 404; это не проверка поведения будущего хостинга.
- `git diff --check`: без ошибок пробелов; Git предупредил о будущей нормализации LF → CRLF в `SiteHeader.astro`.

## Ограничения

- Это согласованный простой список: фильтрация, сортировка и группировка по годам отложены.
- `ArticleLayout` сохранён без изменений: в хлебных крошках статей «Архив» пока остаётся недоступным текстом, а внизу есть старое пояснение «Страница выпуска готовится». Рабочая ссылка архива есть в общей шапке; возврат к выпускам проверен.
- Проверки выполнены в Chromium, не на физических устройствах и не во всех браузерах. Публикация и настройка хостинга не выполнялись.
