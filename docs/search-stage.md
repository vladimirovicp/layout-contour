# Поиск: статичная рамка

## Результат и файлы

- `src/components/SearchForm.astro`: HTML-форма с подписанным `input type="search" name="q"`, подсказками и отключённой кнопкой `type="submit"`. Готовых компонентов полей и кнопок не было: добавлены только необходимые scoped-стили на существующих токенах, без отдельной библиотеки элементов управления.
- `src/pages/search.astro`: `BaseLayout`, `Breadcrumbs`, `SearchForm` и подписанная область с контейнером `#search-results`, подготовленным для будущего вывода результатов. Пока показано честное пояснение об отсутствии поиска и ссылка в архив; имитации выдачи и числа найденных статей нет.
- `src/components/SiteHeader.astro`: ссылка «Поиск» включена и имеет `aria-current="page"` на странице поиска; примечание сообщает о статичном этапе.

Токены, другие шаблоны и страницы, данные статей и зависимости не менялись. Предыдущие изменения сохранены.

## Проверки

- `npm run check`: 24 файла, 0 ошибок, предупреждений и подсказок.
- `npm run build`: успешная статическая сборка, 22 страницы, включая `/search/`.
- Chromium / Playwright, production preview, 390 и 1440 CSS-пикселей: HTTP 200, один `h1`, одна форма поиска, поле связано с видимым `label` и двумя пояснениями, кнопка отключена, один контейнер результатов, клиентских скриптов и карточек фиктивной выдачи нет.
- На 390 px поле и кнопка расположены вертикально, ширина 350 px; на 1440 px — в строку в колонке 792 px. Высота обоих элементов 50 px. Скриншоты просмотрены.
- Поле принимает текст, виден сплошной контур фокуса 3 px. Enter при пустом и заполненном поле не меняет URL и содержимое области результатов; сетевых запросов во время этих действий нет.
- Длинный запрос и текст 200% не вызывают горизонтального переполнения страницы на обеих ширинах.
- Проверены переходы в архив из области результатов, на главную из хлебных крошек и обратно через «Поиск» в шапке.
- `git diff --check`: без ошибок пробелов; Git предупреждает о будущей нормализации LF → CRLF в ранее изменённых файлах.

## Ограничения этапа

Поиск намеренно не работает: нет индекса, фильтрации, обработки `q`, сохранения запроса или обновления результатов. Кнопка недоступна по согласованному плану; JavaScript и обработчики событий не добавлены. Проверки выполнены в Chromium, не во всех браузерах и не на физических устройствах. Публикация не выполнялась.
